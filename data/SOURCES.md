## Procedure when a source is first used

1. Read the terms at the URL on that day and record the date and a one-line summary in this table.
2. Download to a directory outside the repository.
3. Run `write_manifest` over the files and commit the manifest under `data/manifests/`.
4. Fit or derive what is needed and commit only the result (`data/presets.yaml` or a small fixture) with the manifest name in its `fitted_from` field.

## P5 downloads and fixtures (2026-10-31)

DTCC SDR public dissemination, rates. Files `CFTC_CUMULATIVE_RATES_YYYY_MM_DD.zip` from `https://kgc0418-tdw-data-0.s3.amazonaws.com/cftc/eod/` (the end-of-day slices behind https://pddata.dtcc.com/ppd/), business days 2025-10-01 to 2025-10-14 except 2025-10-13 (SIFMA-recommended close), downloaded unattended with `ratesresearch.data.dtcc.download` on 2026-10-31 into a directory outside the repository. Terms: DTCC public price dissemination data under CFTC Part 43; DTCC terms of use apply; raw files are not redistributed. The manifest `data/manifests/dtcc_rates_2025-10.json` records each file's name, size and SHA-256, the URL pattern, the licence note and the download date. Committed result: preset `usd_rfq_flow` (4,342 filtered USD SOFR OIS trades; `ratesresearch.flow.fit_dtcc`). `data/fixtures/dtcc/rates_layout_fixture.csv` is ten hand-written rows in the DTCC column layout for the loader's tests; it is not DTCC data.

FINRA TRACE Treasury transaction data (on-the-run nominal coupons, disseminated since 31 March 2025). Not downloaded: `https://api.finra.org` answered HTTP 401 without an authenticated account on 2026-10-31, so it cannot be fetched unattended. `ratesresearch.data.finra` loads the layout documented in that module, and `data/fixtures/finra/treasury_trades_fixture.csv` is a synthetic file in that layout (cusips `SYNTH0000` onward, generated by `finra.write_synthetic_fixture`). Nothing fitted from it feeds the simulator (DR-P5-04).
